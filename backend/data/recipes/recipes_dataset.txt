# 家常菜
================================================================================

---
菜名：西红柿炒鸡蛋
分类：家常菜
烹饪时间：10分钟
难度：简单
适合人群：所有人
主要食材：鸡蛋、西红柿

食材清单：
- 鸡蛋 3个
- 西红柿 2个（约300g）
- 食用油 2汤匙
- 盐 适量
- 白糖 半茶匙（提鲜，可省略）
- 葱花 少许

烹饪步骤：
1. 鸡蛋打入碗中，加少许盐，用筷子充分搅散备用。
2. 西红柿洗净，去蒂，切成滚刀块或月牙形片，稍大块口感更好。
3. 锅中倒油，大火烧至七成热，倒入蛋液，快速翻炒至蛋液凝固成块后盛出。
4. 原锅留少许底油，放入葱花爆香，下西红柿大火翻炒，用锅铲略压，炒出汤汁。
5. 倒入炒好的鸡蛋，加盐、白糖调味，翻炒均匀出锅。

小贴士：
- 鸡蛋炒至刚凝固即可盛出，不要过火，保持嫩滑。
- 喜欢汤汁多的可以多炒一会儿西红柿，让其充分出汁。
- 最后加盐避免过早出水，影响口感。

营养价值：富含蛋白质、维生素C、番茄红素，是补充维生素的经典搭配。

菜名：蒜蓉炒菠菜
分类：家常菜
烹饪时间：8分钟
难度：简单
适合人群：所有人
主要食材：菠菜、大蒜

食材清单：
- 菠菜 400g
- 大蒜 4瓣
- 食用油 1.5汤匙
- 盐 适量
- 生抽 半茶匙（可选）

烹饪步骤：
1. 菠菜择去老叶，切去根部，洗净后控干水分，切成约5cm长段。
2. 大蒜拍碎，切成蒜末备用。
3. 锅中烧水，水开后放入菠菜焯烫30秒，捞出过凉水，挤去多余水分。
4. 锅中倒油，烧热后下蒜末，小火煸炒至金黄出香。
5. 放入焯好的菠菜，转大火快速翻炒，加盐调味，翻炒均匀即可出锅。

小贴士：
- 菠菜焯水可去除大部分草酸，减少涩味，同时保持翠绿颜色。
- 炒制时间不宜过长，大火快炒保持脆嫩口感。

营养价值：菠菜富含铁、叶酸、维生素K，搭配大蒜有助于促进铁的吸收。

菜名：土豆丝炒青椒
分类：家常菜
烹饪时间：15分钟
难度：简单
适合人群：所有人，素食友好
主要食材：土豆、青椒

食材清单：
- 土豆 2个（约300g）
- 青椒 2个
- 干辣椒 2根（可选，喜辣者加）
- 食用油 2汤匙
- 盐 适量
- 白醋 1茶匙
- 花椒 几粒（可选）
- 葱丝、蒜片 少许

烹饪步骤：
1. 土豆去皮，切成细丝，浸泡在冷水中10分钟，去除多余淀粉，防止粘锅。
2. 青椒去蒂去籽，切成细丝备用。
3. 锅中烧水，土豆丝入沸水焯烫1分钟，捞出过冷水备用。
4. 锅中热油，下花椒、干辣椒爆香后捞出，放葱丝蒜片炒香。
5. 下青椒丝大火翻炒1分钟，再放入土豆丝，加盐、白醋快速翻炒均匀。
6. 炒至土豆丝断生透明即可出锅。

小贴士：
- 加白醋是关键，使土豆丝口感爽脆不软烂，颜色也更白亮。
- 土豆丝尽量切得粗细均匀，保证受热一致。

营养价值：土豆富含维生素C、钾，青椒维生素C含量极高，是补充维生素的好选择。

菜名：红烧豆腐
分类：家常菜
烹饪时间：20分钟
难度：简单
适合人群：素食友好，老人儿童适宜
主要食材：豆腐、葱姜蒜

食材清单：
- 北豆腐 1块（约400g）
- 大葱 1段
- 姜 3片
- 大蒜 3瓣
- 食用油 3汤匙
- 生抽 2汤匙
- 老抽 半茶匙（上色用）
- 白糖 半茶匙
- 盐 适量
- 淀粉水 适量（1茶匙淀粉+2汤匙清水）
- 清水 100ml

烹饪步骤：
1. 豆腐切成约1.5cm厚的方块，用厨房纸吸干表面水分。
2. 锅中倒油，烧至七八成热，放入豆腐块，中火煎至两面金黄，约3分钟每面，盛出备用。
3. 锅内留少许底油，下葱段、姜片、蒜瓣爆香。
4. 加入生抽、老抽、白糖和清水，搅拌均匀，烧开。
5. 放入煎好的豆腐，轻轻翻拌，中小火焖烧5分钟，让豆腐吸入味道。
6. 加盐调味，倒入淀粉水勾薄芡，大火收汁至浓稠，撒葱花出锅。

小贴士：
- 豆腐煎前充分控水，下锅后不要急于翻动，等底面结壳再翻。
- 焖煮阶段火不要太大，防止豆腐碎散。

营养价值：豆腐蛋白质含量丰富，含钙量高，适合补钙人群。

菜名：醋溜白菜
分类：家常菜
烹饪时间：10分钟
难度：简单
适合人群：所有人，素食友好
主要食材：白菜、干辣椒

食材清单：
- 白菜 半棵（约500g）
- 干辣椒 3根
- 花椒 少许
- 食用油 2汤匙
- 白醋 2汤匙
- 生抽 1汤匙
- 盐 适量
- 白糖 半茶匙
- 蒜末 少许

烹饪步骤：
1. 白菜洗净，手撕成大片或斜刀切成宽条，菜帮和菜叶分开放。
2. 干辣椒剪成小段，去籽以减少辣度。
3. 白醋、生抽、白糖、盐调成料汁备用。
4. 锅中大火热油，下花椒、干辣椒爆香出色，加入蒜末翻炒。
5. 先下菜帮大火翻炒1分钟，再放菜叶继续翻炒。
6. 沿锅边烹入料汁，大火翻炒均匀，约30秒即可出锅，保持脆嫩。

小贴士：
- 全程大火快炒是关键，时间过长白菜会出水变软。
- 料汁沿锅边淋入，高温瞬间激发香味。

营养价值：白菜热量低，富含维生素C和膳食纤维，是减脂期的好选择。

菜名：韭菜炒鸡蛋
分类：家常菜
烹饪时间：10分钟
难度：简单
适合人群：所有人
主要食材：韭菜、鸡蛋

食材清单：
- 韭菜 200g
- 鸡蛋 3个
- 食用油 2汤匙
- 盐 适量
- 虾皮 少许（可选，提鲜）

烹饪步骤：
1. 韭菜洗净控干，切成约3cm的小段，白色根部和绿色叶部分开放置。
2. 鸡蛋打散，加少许盐搅匀。
3. 锅中热油，倒入蛋液炒成嫩炒蛋，用铲子划散成小块，盛出备用。
4. 原锅加少许油，先下韭菜白色根部大火翻炒30秒，再下绿色叶部和虾皮。
5. 快速翻炒几下，倒入鸡蛋，加盐调味，翻匀立即出锅。

小贴士：
- 韭菜炒的时间极短，炒过头会变黄出水，口感变差。
- 鸡蛋不要炒太老，嫩滑口感与韭菜更搭。

营养价值：韭菜含有大量膳食纤维和维生素K，有助于消化。

# 快手菜（15分钟内）
================================================================================

---
菜名：番茄鸡蛋汤
分类：快手菜、汤品
烹饪时间：10分钟
难度：极简
适合人群：所有人，老人儿童适宜
主要食材：西红柿、鸡蛋

食材清单：
- 西红柿 2个
- 鸡蛋 2个
- 食用油 1汤匙
- 盐 适量
- 白糖 少许
- 葱花、香菜 少许
- 清水 600ml
- 香油 几滴（可选）

烹饪步骤：
1. 西红柿洗净切成小块，鸡蛋打散备用。
2. 锅中倒油烧热，下西红柿翻炒，用铲子压碎出汁，炒约1分钟。
3. 倒入清水，大火烧开，加盐、白糖调味。
4. 水开后转中火，将蛋液画圈慢慢倒入，用勺子轻轻推散形成蛋花。
5. 出锅前滴几滴香油，撒葱花和香菜即可。

小贴士：
- 蛋液要在汤沸腾时缓慢倒入，才能形成漂亮的蛋花。
- 不喜欢香菜可以不加。

营养价值：低卡开胃，维生素C丰富，适合作为清淡晚餐的配汤。

菜名：蒜蓉西兰花
分类：快手菜
烹饪时间：12分钟
难度：简单
适合人群：所有人，健身人群首选
主要食材：西兰花、大蒜

食材清单：
- 西兰花 1颗（约400g）
- 大蒜 5瓣
- 食用油 2汤匙
- 盐 适量
- 生抽 1茶匙
- 鸡精 少许（可选）

烹饪步骤：
1. 西兰花分成小朵，用淡盐水浸泡10分钟，洗净控干。
2. 大蒜拍碎切末备用。
3. 锅中烧水，水开后加少许盐，放入西兰花焯烫1.5分钟，捞出过冷水，保持翠绿。
4. 锅中热油，下蒜末小火煸炒至微黄出香。
5. 放入西兰花，大火翻炒，加盐、生抽调味，炒匀出锅。

小贴士：
- 焯水后过冷水是保持翠绿颜色的关键步骤。
- 炒制时间不宜过长，保持西兰花的脆嫩口感。

营养价值：西兰花富含维生素C、维生素K和抗癌物质萝卜硫素，是公认的超级食物。

菜名：平底锅培根鸡蛋
分类：快手菜、早餐
烹饪时间：8分钟
难度：极简
适合人群：所有人，早餐推荐
主要食材：培根、鸡蛋

食材清单：
- 培根 3片
- 鸡蛋 2个
- 黑胡椒粉 少许
- 盐 少许（培根本身有咸味，少加或不加）

烹饪步骤：
1. 平底锅中火预热，不需要加油（培根自身会出油）。
2. 放入培根片，煎至两面微焦，约1-2分钟每面，盛出备用。
3. 锅中留培根油，转中小火，磕入鸡蛋，煎至蛋白凝固。
4. 撒少许盐和黑胡椒，喜欢全熟的可加盖煎1分钟。
5. 培根和鸡蛋装盘，搭配吐司或面包即可。

小贴士：
- 培根油脂丰富，煎鸡蛋前无需额外加油。
- 蛋黄流心口感最佳，注意掌握火候。

营养价值：高蛋白早餐，能提供持久饱腹感，适合上班族快速准备。

菜名：黄瓜拍蒜
分类：快手菜、凉拌
烹饪时间：5分钟
难度：极简
适合人群：所有人，夏季推荐
主要食材：黄瓜、大蒜

食材清单：
- 黄瓜 2根
- 大蒜 4瓣
- 盐 1茶匙
- 白醋 1汤匙
- 香油 1茶匙
- 生抽 半汤匙
- 干辣椒碎 少许（可选）
- 白糖 半茶匙

烹饪步骤：
1. 黄瓜洗净，用刀面拍碎，再斜刀切成小段，拍碎能更好入味。
2. 大蒜拍碎切成粗蒜末。
3. 黄瓜放入盆中，加盐抓匀，腌制5分钟，用手挤去多余水分。
4. 加入蒜末、白醋、香油、生抽、白糖和辣椒碎，拌匀即可。

小贴士：
- 拍黄瓜而不是切，截面粗糙更容易吸附调料。
- 腌制后挤水是关键，避免成品太稀、味道被稀释。

营养价值：黄瓜含水量高，热量极低，是夏季消暑的绝佳选择。

菜名：鸡蛋炒饭
分类：快手菜、主食
烹饪时间：10分钟
难度：简单
适合人群：所有人，剩饭利用
主要食材：米饭、鸡蛋

食材清单：
- 隔夜米饭 2碗
- 鸡蛋 2个
- 葱花 适量
- 食用油 2汤匙
- 盐 适量
- 生抽 1茶匙
- 白胡椒粉 少许

烹饪步骤：
1. 鸡蛋打散，加少许盐搅匀。
2. 隔夜米饭用手或勺子提前打散，去除结块。
3. 锅中热油至七成热，倒入蛋液快速翻炒，炒至半凝固状态。
4. 立即倒入米饭，转大火，用铲子快速翻炒，将鸡蛋与米饭充分混合。
5. 加盐、生抽、白胡椒粉调味，翻炒均匀，米粒分明。
6. 撒葱花翻匀出锅。

小贴士：
- 隔夜冷饭水分少，炒出来更粒粒分明，新鲜米饭容易粘锅。
- 全程大火，快速翻炒，不要在锅里停留太久。

营养价值：均衡的碳水与蛋白质搭配，简单饱腹，是消耗剩饭的最佳方式。

# 川菜
================================================================================

---
菜名：麻婆豆腐
分类：川菜
烹饪时间：20分钟
难度：中等
适合人群：喜辣人群，不适合儿童和辣椒敏感者
主要食材：豆腐、猪肉末、郫县豆瓣酱

食材清单：
- 嫩豆腐 1块（约400g）
- 猪肉末 100g
- 郫县豆瓣酱 2汤匙
- 豆豉 1汤匙（剁碎）
- 大蒜 4瓣（切末）
- 姜末 1茶匙
- 葱花 适量
- 食用油 3汤匙
- 生抽 1汤匙
- 清水 200ml
- 花椒粉 1茶匙
- 淀粉水 适量（2茶匙淀粉+3汤匙清水）

烹饪步骤：
1. 嫩豆腐切成约1.5cm的小方块，入盐水中浸泡5分钟，防止碎散，捞出备用。
2. 锅中热油，下猪肉末，中火炒散至变色出油。
3. 下郫县豆瓣酱和豆豉，小火炒出红油，约2分钟，炒出香味是关键。
4. 加入姜末、蒜末继续翻炒出香，约30秒。
5. 倒入清水和生抽，搅匀烧开。
6. 轻轻放入豆腐块，中火煮2-3分钟，期间用勺子轻推，不要用铲子搅拌以防豆腐碎。
7. 分两次淋入淀粉水，轻轻推匀勾芡至汤汁浓稠，亮而不流。
8. 出锅撒花椒粉和葱花。

小贴士：
- 麻婆豆腐讲究"麻、辣、鲜、嫩、烫"，豆腐保持完整是美观关键。
- 花椒粉最后撒，保留最鲜的麻香。

营养价值：富含优质植物蛋白，豆瓣酱提供发酵风味，但钠含量较高，高血压患者注意用量。

---
菜名：回锅肉
分类：川菜
烹饪时间：40分钟（含煮肉时间）
难度：中等
适合人群：喜辣人群
主要食材：五花肉、青椒、蒜苗

食材清单：
- 带皮五花肉 300g
- 青椒 2个
- 蒜苗 2根
- 郫县豆瓣酱 2汤匙
- 甜面酱 1茶匙
- 生抽 1茶匙
- 白糖 半茶匙
- 食用油 1汤匙
- 姜片 3片
- 料酒 1汤匙

烹饪步骤：
1. 五花肉冷水入锅，加姜片、料酒，水开后煮20分钟至筷子能插入，捞出晾凉。
2. 晾凉后切成约3mm厚的薄片。
3. 青椒去籽切菱形片，蒜苗斜切段，白绿分开放置。
4. 锅中放少许油，下五花肉片中小火慢慢煸炒，逼出多余油脂，至肉片微卷呈"灯盏形"。
5. 肉片推至锅边，利用锅中猪油下郫县豆瓣酱，小火炒出红油。
6. 加甜面酱、生抽、白糖翻炒均匀，与肉片混合。
7. 下青椒和蒜苗白色部分大火翻炒，最后加入蒜苗绿叶部分，翻炒均匀出锅。

小贴士：
- 五花肉煸炒至"灯盏形"（边缘微卷翘起）是回锅肉的标志性状态，此时油脂充分释放，口感不腻。
- 郫县豆瓣酱要充分炒出红油，这是回锅肉红亮色泽和香味的来源。

营养价值：五花肉含较多脂肪，适量食用，搭配蔬菜均衡营养。

# 附：常见食材去腥技巧
================================================================================

肉类去腥：冷水下锅焯水（不是热水），加姜片和料酒，水开后去浮沫。
鱼类去腥：用姜片和葱段腌制，柠檬汁或白醋浸泡5分钟。
豆腐去腥：用盐水浸泡10分钟，或提前在沸盐水中焯烫1分钟。
内脏去腥：反复清洗，加白醋或淀粉揉搓，冷水焯烫。

# 附：新手常见问题解答
================================================================================

Q：为什么炒菜总是粘锅？
A：锅没充分预热，或油量不足。建议先将锅烧热再倒油，"热锅冷油"是防粘的关键。

Q：怎样让炒出来的蔬菜保持翠绿？
A：大火快炒，缩短加热时间；炒前可焯水，之后过冷水锁色；出锅前不要加盖闷。

Q：如何判断油温是否合适？
A：插入木筷，周围冒小泡为五六成热（适合炒蔬菜）；快速冒大泡为七八成热（适合炸制）。

Q：汤做得太咸怎么办？
A：放入一个去皮土豆块煮几分钟，土豆会吸收多余盐分；或加入少量白糖平衡咸味。

Q：肉怎么炒才嫩？
A：切肉时逆纹路切；腌制时加淀粉和少量食用油锁住水分；大火快炒不要过度加热。
